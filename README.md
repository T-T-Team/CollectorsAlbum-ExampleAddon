# Disable default features
This datapack disables all features provided by default by this mod such as cards, categories, drops and so on. This may be helpful for some modpack developers who want to create completely custom experience.

## Installation
Download the zip file from [Releases tab](https://github.com/T-T-Team/CollectorsAlbum-ExampleAddon/releases) and add it to your datapack directory. If you want to disable only parts of the mod, you can delete the unwanted overrides from the datapack.
