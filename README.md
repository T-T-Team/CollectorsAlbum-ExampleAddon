# Example datapack for Collector's Album
This repository serves just as a storage for [step by step guide](https://github.com/T-T-Team/CollectorsAlbum/wiki/Custom-addon-%E2%80%90-Step-by-step) in the original mod repository.

This example pack was written for Minecraft 1.21 for mod versions starting from 2.0. If you are on older version of Minecraft, this pack should be functional, but there is change in how custom pack paths are set using commands - if you want to
give yourself customized pack, use this command format: `/give @s collectorsalbum:epic_custom_card_pack{"collectorsalbum:packs_drop_table"="dyes:dyes_drops"}` (credits to [@ChosenArchitect](https://github.com/ChosenArchitect) for pointing this out)
